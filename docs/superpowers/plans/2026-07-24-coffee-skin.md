# Кофейно-ламповый скин «coffee» — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить новый дефолтный скин дашборда с тёплой кофейной палитрой и «ламповым» янтарным свечением (dark) + кремовым латте (light).

**Architecture:** Скин — один самодостаточный `index.css`: `@import` общих `base/*.css` (структура) + палитра токенов для `data-theme` dark/light + перекраска захардкоженных в base neon-заливок под кофейную палитру (по образцу существующего скина `goga`). Компоненты и `base/*.css` не трогаем. Дефолт переключается строкой `<link>` в `index.dev.html` (источник; `index.html` регенерируется сборкой).

**Tech Stack:** статический CSS (custom properties), Vite (сборка/копирование `public/` → корень), Go `//go:embed` (встраивание собранных ассетов).

**Спека:** `docs/superpowers/specs/2026-07-24-coffee-skin-design.md`.

## Global Constraints

- Скины и ассеты живут в двух местах: `public/skins/…` (источник, dev) и `skins/…` (билд-выход, который встраивает `//go:embed`). **Правки — только в `public/skins/…`**; `skins/…` и `index.html` регенерирует `npm run build`.
- **Логотип не трогать:** не переопределять `#header h1` / `.logo`.
- **Не менять версию go в go.mod.** После правок линт не должен ругаться (пре-коммит хук сам гоняет `make lint` + `make build`).
- Коммиты на русском, без `Co-Authored-By`. Не пушить (пуш делает пользователь).
- У скинов нет юнит-тестов — проверка это `npm run build` (успех) + `tsc` + существующие тесты (зелёные) + `go build` + визуальный осмотр.
- `git push` не выполнять.

## File Structure

- **Create:** `pkg/web/dashboard/public/skins/coffee/index.css` — единственный новый файл (палитра + декор + перекраска). Источник.
- **Modify:** `pkg/web/dashboard/index.dev.html` — одна строка `<link>` skin.
- **Regenerated by build (коммитим вместе):** `pkg/web/dashboard/skins/coffee/index.css` (копия public/), `pkg/web/dashboard/index.html` (собранный, со ссылкой на coffee).
